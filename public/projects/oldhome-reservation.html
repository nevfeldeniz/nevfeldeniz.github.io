Project

OldHome Reservation Management System

Butik otel operasyonları için geliştirilmiş rezervasyon yönetim sistemi. Resepsiyonda kullanılan Windows masaüstü uygulaması (Electron / EXE) ile uzaktan erişilebilen web yönetim paneli aynı merkezi NestJS API ve PostgreSQL veritabanı üzerinden çalışır.

Electron JavaScript NestJS PostgreSQL React

Web yönetim paneli

Özel yönetim arayüzü — giriş, dashboard ve oda durumu (herkese açık erişim yok).

Windows uygulaması (EXE)

Masaüstü arayüzünden seçilmiş ekranlar.

Mimari

  • Masaüstü uygulama (EXE): Electron istemci; Windows kurulum / taşınabilir sürüm.
  • Merkezi API: NestJS REST API; oturum, rezervasyon, rapor ve yedekleme.
  • Web yönetim paneli: React PWA; rol ve izin kontrollü sayfalar.
  • Veritabanı: PostgreSQL.

Öne çıkan özellikler

  • Oda durumu, takvim ve rezervasyon oluşturma / düzenleme
  • Ödeme takibi (nakit, havale, kart); kısmi ve tam ödeme
  • Muhasebe ve kredili şirket / misafir alacak takibi
  • Finansal raporlar ve Excel dışa aktarma
  • Rol tabanlı yetkilendirme ve JWT oturum yönetimi

Özel / ticari proje — herkese açık kaynak kodu yoktur.
