Project

OldHome Reservation Management System

Butik otel operasyonları için geliştirilmiş rezervasyon yönetim sistemi. Resepsiyonda kullanılan Windows masaüstü uygulaması (Electron / EXE) ile uzaktan erişilebilen web yönetim paneli aynı merkezi NestJS API ve PostgreSQL veritabanı üzerinden çalışır.

Web yönetim paneli
Electron JavaScript NestJS PostgreSQL React

Windows uygulaması (EXE) — ekran görüntüleri

OldHome Rezervasyon masaüstü arayüzünden alınmıştır. Web paneli aynı işlevleri tarayıcıda sunar.

Mimari

  • Masaüstü uygulama (EXE): Electron istemci; Windows’ta kurulumlu / taşınabilir sürüm; resepsiyon ve günlük operasyonlar.
  • Merkezi API: NestJS REST API; oturum, rezervasyon, rapor ve yedekleme uç noktaları.
  • Web yönetim paneli: React tabanlı PWA; rol ve izin kontrollü sayfalar (dashboard, odalar, rezervasyonlar, raporlar).
  • Veritabanı: PostgreSQL (Docker ile dağıtılan merkezi veri katmanı).

Öne çıkan özellikler

  • Oda durumu, takvim ve rezervasyon oluşturma / düzenleme akışları
  • Ödeme durumu takibi (nakit, havale, kart); kısmi ve tam ödeme hesaplaması
  • Muhasebe görünümü ve kredili şirket / misafir alacak takibi
  • Finansal raporlar: günlük, aylık, genel özet ve Excel arşivi
  • Rol tabanlı yetkilendirme (admin, yönetici, resepsiyon, muhasebe) ve izin korumalı rotalar
  • Merkezi yedekleme ve oturum yönetimi (JWT, oturum yenileme)
